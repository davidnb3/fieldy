Set up your library

Choose a folder on this Mac. Fieldy will sort dropped audio into AudioSet class folders (for example Siren, Animal, or Speech). The app never creates all AudioSet folders up front.

Move relocates the file into your library. Copy leaves the original where it is and adds a tagged file to the library. You can change this later in Settings.

Drop audio files or folders here

WAV, AIFF, FLAC, and MP3. Fieldy listens, tags, and files them into your library. The first file can take a minute while Fieldy gets ready.

    Move relocates the file. Copy leaves the original in place and tags only the library file. Undo reverses that drop.

    Each AudioSet class is scored from 0 to 1. Only classes at or above this value become tags, and the file’s folder is the top class that clears it. Lower (for example 0.2) tags more classes; higher (for example 0.5) is stricter and more files may land in Mixed. Default is 0.3.

    Change library folder?

    Fieldy will then watch a different folder. The files and folders in your current library will not show up in Fieldy anymore. You can move everything to the new location (stars stay with the files), or leave the current library on disk and start empty in the new folder.
